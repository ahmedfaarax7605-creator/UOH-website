# University of Hargeisa Website 🎓

A modern and responsive university website built using **HTML, CSS, and JavaScript** to showcase the academic programs, admissions, colleges, and other essential information of the University of Hargeisa.

## ✨ Features
- Responsive homepage and navigation menu
- Colleges, schools, and institutes pages
- Admissions, tuition, and scholarship information
- Research, news, and contact sections
- Clean design and interactive elements

## 🛠️ Technologies
- HTML5
- CSS3
- JavaScript
- Git & GitHub
